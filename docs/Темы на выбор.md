# 30 тем на выбор

Согласуйте номер с преподавателем: в группе темы распределяются без повторов. Если варианты заняты, преподаватель назначает другое содержание с тем же контрактом.

Во всех темах: каталог → выбор → заявка на количество → проверка остатка → отмена. Для событий предложение — фиксированная встреча без подбора времени и пересечений расписания; для вещей — резерв запаса без срока аренды, залога и логистики. «Обмен» означает резервирование выдачи.

Названия категорий можно уточнить, сохранив три осмысленные группы. Каталог, тексты, название и визуальное оформление придумайте самостоятельно по R1–R2. `feature` помогает выбирать и не добавляет нового серверного правила. Контракт, контрольные ёмкости `item-a`/`item-b` (5/8), проверки и баллы одинаковы для всех тем.
