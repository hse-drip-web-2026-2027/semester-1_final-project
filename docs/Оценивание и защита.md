# Оценивание и защита

**40 пунктов × 0,25 = 10 баллов.** Суммируются подтверждённые пункты; невыполненный пункт получает 0 с пояснением, без повторных вычитаний. Дополнительные функции не повышают максимум. Критерии одинаковы для всех тем и не меняются задним числом.

Код, тест и объяснение оцениваются отдельно. Изолированно работающая функция может получить баллы даже при незавершённой интеграции. Выданные конфигурации не дают автоматических баллов: подтвердите их работу на своих исходниках; переписывать их ради авторства не нужно.

## Защита

Защита проходит **без ИИ и генеративного автодополнения**. Свой код, документация, DevTools и обычные средства IDE доступны. Формат объявляет преподаватель; фрагменты, входные данные и конкретное изменение он выбирает при проверке.

1. Покажите создание заявки, отказ сверх остатка и отмену. По выбранному полю проследите путь UI → HTTP → сервер → файл → UI.
2. Объясните выбранные части клиента и сервера/инфраструктуры: решение, границу ответственности, проверку. Воспроизведите один результат из своего отчёта на предложенных данных; до запуска предскажите исход.
3. Назовите последствия небольшой правки знакомого правила, внесите её и проверьте обычный/граничный случаи. Примеры типов задач: другая граница количества или комментария, ёмкость предложения с активными/отменёнными заявками. Конкретные значения заранее не фиксируются.

Новая библиотека или маршрут не требуются; работайте в отдельной локальной ветке, сохраняя сдаваемую версию. Проверяются P37–P40 и достоверность предъявленных свидетельств по остальным пунктам. Если результат не воспроизводится, преподаватель фиксирует конкретное расхождение и оценивает соответствующий пункт; один неудачный ответ не обнуляет весь проект.

Стиль кода, число коммитов или вывод детектора ИИ сами по себе не доказывают нарушение. Основание оценки — продемонстрированные результаты и самостоятельные действия. Видео или PR-разбор, если назначены, дополняются индивидуальной проверкой нового условия; одной заранее записанной демонстрации недостаточно.
